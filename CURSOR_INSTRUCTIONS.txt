================================================================================
WHAT THE SCRIPT DOES
================================================================================

The install_mcp_macos.sh script will automatically:

1. Find your Python installation path
2. Upgrade pip to the latest version
3. Install requests and python-dotenv packages
4. Install the MCP SDK (tries multiple methods if needed)
5. Install the Hospitable SDK in development mode
6. Generate the Claude Desktop configuration file
7. Optionally test the MCP server

It handles all the complexity of finding the right paths and installing
dependencies correctly.


================================================================================
TROUBLESHOOTING
================================================================================

If you encounter issues:

1. MCP SDK installation fails:
   Try manually: pip3 install git+https://github.com/modelcontextprotocol/python-sdk.git

2. Permission errors:
   The script uses --user flag for all pip installs to avoid permission issues

3. Claude Desktop shows "Spawn python Enoent":
   - Make sure the config has FULL paths (/usr/bin/python3, not python3)
   - The installation script generates these correctly

4. "Module not found" errors:
   Run: pip3 install --user requests python-dotenv
   And: cd /Users/colinforrester/hospitable-python && pip3 install --user -e .

5. API returns 403 errors:
   - Check that your token is correct in the config
   - Use the same token that works with Data Fetcher
